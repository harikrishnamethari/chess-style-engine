# 07 — Database & Persistence Guide

## 1. Relational Schema & ORM Architecture
The project uses **PostgreSQL** paired with **SQLAlchemy 2.0 Declarative Mapping** (`backend/db/models.py`).

---

## 2. Table Definitions

### Table 1: `users`
Represents unique human players analyzed by the system.
| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INTEGER` | Primary Key, Auto-increment | Unique identifier |
| `username` | `VARCHAR` | Unique, Indexed, Non-null | Lichess handle or custom username |
| `created_at` | `TIMESTAMP` | Default: `NOW()` | Registration timestamp |

Relationships:
- `profiles`: One-to-One / One-to-Many with `PlayerProfile` (Cascading delete).
- `games`: One-to-Many with `Game` (Cascading delete).

---

### Table 2: `player_profiles`
Stores the derived mathematical style fingerprint and historical play metrics.
| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INTEGER` | Primary Key, Auto-increment | Unique identifier |
| `user_id` | `INTEGER` | Foreign Key (`users.id`), Non-null | Owner of this style profile |
| `style_embedding` | `JSON` | Nullable | 32-element float array generated by `HistoryEncoder` |
| `avg_cp_loss` | `FLOAT` | Nullable | Mean centipawn loss across analyzed games |
| `capture_rate` | `FLOAT` | Nullable | Ratio of capture moves to total moves |
| `games_analysed`| `INTEGER` | Default: 0 | Number of PGN games contributing to this profile |
| `updated_at` | `TIMESTAMP` | Default: `NOW()`, OnUpdate: `NOW()` | Last modified timestamp |

---

### Table 3: `games`
Archives the raw PGN history uploaded by users.
| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INTEGER` | Primary Key, Auto-increment | Unique identifier |
| `user_id` | `INTEGER` | Foreign Key (`users.id`), Non-null | Uploader user ID |
| `pgn` | `TEXT` | Non-null | Complete standard PGN text |
| `white_player` | `VARCHAR` | Nullable | White player name from PGN header |
| `black_player` | `VARCHAR` | Nullable | Black player name from PGN header |
| `uploaded_at` | `TIMESTAMP` | Default: `NOW()` | Upload timestamp |

---

## 3. Repositories (`backend/db/repository.py`)
Direct SQLAlchemy queries are strictly restricted to repository classes:
- **`UserRepository.get_or_create(username)`**: Finds an existing user or creates a new row safely.
- **`GameRepository.create(user_id, pgn, white, black)`**: Inserts a new PGN game record.
- **`ProfileRepository.upsert(user_id, style_embedding, avg_cp_loss, capture_rate, games_analysed)`**: Creates a profile on the first upload, or updates existing statistical averages on subsequent uploads.
